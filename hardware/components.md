# Components

## Core Hardware

- ESP32
- Arduino Uno
- Ultrasonic Sensors
- Jumper Wires
- Breadboard
- Battery Module
- Waste Bin Structure

---

## Sensor System

The ultrasonic sensors are responsible for measuring the distance between the waste surface and the sensor module mounted at the top of the bin.

Distance values are used to estimate fill levels.

---

## Controller System

The ESP32 or Arduino processes sensor data and handles communication with external monitoring systems.
