## System Components

### Sensor Layer
Collects fill-level data using ultrasonic distance sensors.

### Embedded Layer
Processes sensor readings using Arduino or ESP32 microcontrollers.

### Cloud Layer
Handles data synchronization and remote monitoring.

### Dashboard Layer
Displays real-time waste-bin analytics and monitoring information.
